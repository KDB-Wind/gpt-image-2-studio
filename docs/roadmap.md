# 路线图

本文只记录公开本地基础工具版的后续工作。平台版、平台部署、托管 Key、注册登录、积分和管理员后台暂不进入本公开仓库路线图。

## 已完成

- 明亮中文界面和中英文切换。
- 文生图、图生图、多图参考和拖拽上传。
- 批量生图：同一提示词多张、自定义多条提示词。
- 批量任务本地草稿持久化。
- 本地历史记录、搜索、过滤和批量删除。
- 单文件 HTML 构建链路。
- GitHub Pages 静态站发布链路。
- Windows `setup.exe` Release 链路。
- Release 校验和基础安全扫描。

## 近期优先级

- 优化静态站首次使用指引和 CORS 诊断。
- 增加更清晰的“海报文字安全模式”：模型只生成背景，中文文字由前端叠加。
- 重新设计提示词模板功能，当前实现后续可能移除。
- 增强不同 OpenAI-compatible 供应商的返回格式兼容。
- 增加更多批量任务手动验收用例。

## 暂缓

- `.msi` 安装包。
- 代码签名。
- 自动更新。
- 浏览器端代理服务。

## 不纳入公开基础工具版

- 用户注册和登录。
- 平台托管 `API key`。
- 积分、充值、支付或兑换码。
- 管理员后台。
- 服务端任务队列。
- 服务端图片存储。
- 平台级供应商调度和健康监控。
