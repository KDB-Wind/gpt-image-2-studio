# 基础工具版使用指南

基础工具版适合个人本地使用。它不包含账号、积分、托管 key、支付、管理员后台或服务端图片存储。

## 使用方式

你可以选择三种方式：

- 在线静态页：打开 [https://kdb-wind.github.io/gpt-image-2-studio/](https://kdb-wind.github.io/gpt-image-2-studio/)。
- 离线 HTML：从 GitHub Release 下载 `gpt-image-2-studio-lite.html`，双击打开。
- 源码开发版：安装依赖后运行 `npm run dev`。

普通用户优先选择在线静态页或离线 HTML。开发者再使用源码开发版。

## 本地开发启动

```powershell
npm install
npm run dev
```

启动后访问终端显示的地址，通常是：

```text
http://localhost:5173/
```

如果端口被占用，可以关闭旧的 Vite 进程，或者使用终端提示的新端口。

## 设置

进入“设置”后填写：

- `API key`
- `Base URL`
- 文字模型
- 图片模型
- 超时时间
- 默认图片尺寸、质量和格式

超时时间可设置为 `60` 到 `600` 秒。快速 1K 测试可以短一些；慢供应商或 2K/4K 生成建议使用 `180` 到 `300` 秒。

建议先点击“测试文字模型”和“测试图片模型”。测试失败仍然可以保存配置，但应先排查密钥、模型名、供应商状态或 CORS。

## 生成

“生成”菜单适合单次任务：

- 不上传图片时是文生图。
- 上传参考图片后是图生图。
- 最多支持 8 张参考图片，建议不超过 4 张。
- 可以填写图片名称；不填写时会自动命名。

如果图片里需要大量中文文字，建议让模型只生成背景，文字后期由工具或设计软件叠加。图片模型不适合稳定渲染大量中文姓名和小字。

## 批量

“批量”菜单适合一次生成多张图：

- 同一提示词生成多张：适合做变体。
- 自定义多条提示词：适合一次执行多张不同主题或风格的图。

批量并发数代表同时发起多少个图片 API 请求。并发越高，速度可能越快，但限流、失败和费用风险也更高。保守建议：

```text
并发数：1 到 3
间隔秒数：10 到 60
失败重试：1
```

切换菜单不会清空批量草稿。需要重新开始时点击“一键清空”。

## 历史

历史记录保存在当前浏览器本地。你可以查看、搜索、复用提示词或删除历史记录。

HTML 版受浏览器权限限制，刷新后能否预览旧图片，取决于你是否在“设置”里完成目录授权并通过“测试保存目录”。只手动填写路径或只看到目录名，都不等于浏览器已经获得读写权限。

## 安全提醒

- 不要把真实 `API key` 发到 Issue、截图、日志或聊天记录里。
- 不要在公共电脑保存自己的 key。
- 在线静态页和离线 HTML 都是用户自己填 key、自己调用供应商。
- 如果供应商不支持 CORS，请使用桌面版或更换供应商。
