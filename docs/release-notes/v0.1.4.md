# GPT-Image-2 Studio v0.1.4

本次发布继续优化公开静态 HTML 工具版，重点是批量生图、历史预览和长提示词输入体验。

## 亮点

- 批量生图支持“同一提示词生成多张”和“自定义多条提示词”两种主流程。
- 在“同一提示词生成多张”内部恢复 AI 拆分提示词能力，可让文字模型把主任务规划为多个子任务。
- 批量任务支持全局参考图和子任务独立参考图，方便批量图生图场景。
- 批量执行结果增加预览区，完成后可以直接查看成功图片。
- 历史记录支持通过浏览器目录授权恢复旧图片预览。
- 优化长提示词、实际发送内容、图片名称等输入框尺寸，避免页面被长文本撑开。
- 更新页面 Logo、GitHub 项目入口和部分中文提示文案。

## 下载建议

普通用户优先选择：

- 想最快试用：下载 `gpt-image-2-studio-lite.html`，双击打开。
- 想在线使用：访问 GitHub Pages 静态页面。

使用前需要自行填写 `API key`、`Base URL` 和模型名。配置保存在当前浏览器本地，不会写入发布文件。

## 范围说明

本 Release 只包含公开基础工具版能力，不包含平台版注册、积分、支付、管理员后台、平台托管 Key、服务端队列或私有图片后处理功能。
