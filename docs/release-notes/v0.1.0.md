# GPT-Image-2 Studio v0.1.0

首个公开轻量工具版 Release。

## 适合谁使用

适合已经拥有 OpenAI-compatible `API key` 的个人用户，在本地调用 `gpt-image-2` 进行图片生成。

## 普通用户下载

请优先下载 `setup.exe` 安装包。源代码运行方式主要推荐开发者使用。

Release 附件会同时提供 `SHA256SUMS.txt`。如需校验安装包完整性，可以用 PowerShell 执行：

```powershell
Get-FileHash .\GPT-Image-2-Studio_0.1.0_x64-setup.exe -Algorithm SHA256
```

## 主要功能

- 默认中文界面，支持切换 English。
- 支持 `API key`、`Base URL`、文字模型、图片模型和输出目录配置。
- 支持文生图。
- 支持图生图。
- 支持最多 8 张参考图上传，推荐不超过 4 张。
- 支持拖拽多图上传。
- 支持图片尺寸、质量、格式和压缩参数。
- 支持提示词模板和自定义模板。
- 支持本地历史记录、搜索、过滤、复用和批量删除。
- 支持本地输出目录保存。
- 支持右下角作者支持入口。

## 已知限制

- 首版 Windows 安装包暂未代码签名，可能触发 SmartScreen 提示。
- Web 版本不能直接打开本地输出文件夹，这是浏览器权限限制。
- 图片模型请求失败时可能仍然产生服务商计费，本工具不会自动重试。
- 本仓库不包含注册、支付、托管 Key、服务器存储或平台级熔断功能。
