# v0.1.12 · Studio interface refresh

## 中文

- 收紧页头和导航，给桌面结果预览留出更多空间。
- 更新单图、批量、历史、设置和首次引导的视觉样式。手机端保留按标签切换的单列布局。
- 主操作按钮使用 15 px 字号。普通和悬停状态的文字对比度达到 WCAG AA。
- 包含 [v0.1.11 中记录的桌面设置、历史预览与安全保存修复](./v0.1.11.md)。

## English

- Use a compact header and tabs. Give image previews more room on desktop.
- Refresh the single-image and batch workspaces, history, settings, and onboarding. Keep the tab-based, single-column layout on mobile.
- Use 15 px text on primary buttons. Default and hover states meet WCAG AA text contrast.
- Include the [desktop settings, history preview, and save recovery fixes recorded for v0.1.11](./v0.1.11.md).
