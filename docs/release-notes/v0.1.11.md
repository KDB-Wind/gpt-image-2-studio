# v0.1.11 — Desktop persistence and safe save recovery

## 中文

- 修复 Windows 桌面保存配置时的 IPC 参数封装，设置可以正常保存并在进程重启后恢复。
- 按平台启用系统凭据库后端；Windows 原生验收覆盖合成密钥保存、回读、删除及重启恢复。
- 生图完成但保存失败时暂停批次；会话内重试复用图片，只重试保存，不再次请求生成。保存中的恢复标记保留到草稿，恢复后图片缓存已丢失时拒绝静默重新生图。
- 历史预览和打开改为受控原生命令，仅接受已登记图片，并检查格式和大小。
- Web 明确清空密钥时检查持久删除是否成功，失败不再显示为成功保存。
- 保留历史静态归档，新增 v0.1.11 候选。此提交准备可审阅修复，不表示 GitHub Release、Pages 或安装包已发布。

## English

- Fix the desktop settings IPC envelope so configuration survives a native process restart.
- Enable platform credential-store backends; verify synthetic credential write, read, deletion and restart behavior on Windows.
- Pause batches after a generated image cannot be saved, and retry saving the cached image without another generation request. Preserve save-only recovery markers and decline automatic generation when the session cache is gone.
- Read and open history images through native commands restricted to registered images, supported formats and bounded size.
- Report failed persistent Web credential deletion instead of silently treating it as successful.
- Preserve historical static archives and prepare a new v0.1.11 candidate. Publication and installer acceptance remain separate steps.
