# GPT-Image-2 Studio v0.1.9

本版本集中修复供应商设置持久化、桌面密钥隐私语义及生成流程的错误边界：

- 设置页连接字段会同步到当前供应商档案，同一会话请求和重新加载后的配置保持一致。
- 桌面端清空 API key 或关闭“记住 API key”后，会删除当前供应商的系统凭据和本地回退副本，重启不再恢复旧密钥。
- 损坏或暂时不可读的历史记录不再阻断应用启动；图片已保存后，即使历史刷新失败也不会被误报为生成失败。
- 批量任务的重试、清单保存、历史刷新和通知失败不再破坏已经完成的任务状态。
- 选择输出目录不会顺带持久化尚未点击保存的设置草稿。
- 增加相关前端、Tauri、静态页及错误边界回归测试，并更新中英文 README 的密钥存储说明。

本项目继续采用 BYOK 模式，不内置真实 API key。启用桌面端密钥记忆时优先使用系统凭据库；不可用时可能回退到应用配置文件，仅应在可信设备上启用。
