# GPT-Image-2 Studio v0.1.1

本次发布面向公开基础工具版，重点是让普通用户可以直接下载使用。

## 亮点

- 新增单文件 HTML Release 附件：`gpt-image-2-studio-lite.html`。
- 保留 Windows `setup.exe` 桌面安装包链路。
- Release 附带 `SHA256SUMS.txt`，用于校验下载文件。
- 清理公开代码树，仅保留本地基础工具版。
- 增强供应商异常识别，对 `upstream error`、`new_api_error`、`do_request_failed` 等高成本失败给出更明确提示。

## 下载建议

普通用户优先选择：

- 想最快试用：下载 `gpt-image-2-studio-lite.html`，双击打开。
- 想长期使用：下载 Windows `setup.exe` 安装包。

不要下载源码列表里的根目录 `index.html` 作为应用入口。它不是可独立运行的单文件版本。

## 范围说明

本 Release 不包含平台注册、积分、支付、管理员后台、平台托管 Key、服务端队列或服务端图片存储。
