# GPT-Image-2 Studio v0.1.1

本次发布重点是公开工具版的发布链路加固和兼容性修复。

## 亮点

- Windows 安装包现在会同时发布 `SHA256SUMS.txt`。
- Release artifact 增加了保留期，便于短期回溯。
- 图片响应解析兼容性更强，覆盖更多 OpenAI-compatible 返回结构。
- 增加了 UI smoke tests 和窄屏布局 smoke tests。

## 下载建议

普通用户优先下载 `setup.exe`，并可用 `SHA256SUMS.txt` 校验完整性。

```powershell
Get-FileHash .\GPT-Image-2-Studio_0.1.1_x64-setup.exe -Algorithm SHA256
```

## 说明

- 仍然是轻量本地工具版，不包含平台托管 Key、注册、支付或服务器存储。
- 如果图像服务商返回 524 或其它上游错误，应用会提示失败；这不等于本地程序损坏。
