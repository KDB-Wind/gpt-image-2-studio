# GPT-Image-2 Studio v0.1.7

This release preserves the immutable v0.1.6 archive baseline while carrying forward the retry, history durability, output-directory, static isolation, and release verification fixes prepared after v0.1.6.

- Requires an external `STATIC_ARCHIVE_TRUSTED_BASE`; no commit or configuration inside the validated ref can choose the trust root.
- Uses public commit `31774ff698abd999f107e40c49d3de43da5a5f35` as the intended Repository Variable value. That commit contains the complete `v0.1.7` archive, so later checks protect every version through `v0.1.7`.
- Requires maintainers to advance the external trust root after every stable archive or Release before preparing later releases. This note records the intended value only and does not claim the GitHub Repository Variable has already been changed.
- Fails closed when the external base is missing, malformed, unresolved, or not an ancestor, and ignores legacy in-repository or workflow-input bypass paths.
- Lets CI and Pages add protected-branch, merge-base, or event-before comparisons without replacing the external trusted base.
- Removes newly allocated output-folder test files when writable creation or later verification fails, while preserving unknown collisions.
- Verifies that the emitted normal HTML entry graph can reach the Tauri adapter through Vite's manifest; an orphan adapter chunk no longer passes.
