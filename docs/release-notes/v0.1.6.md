# GPT-Image-2 Studio v0.1.6

This release closes the P1 findings from the final public-lite branch review.

- Prevents browser-authorized output folders from overwriting existing image files.
- Requests exactly one billed image per Single or Batch task.
- Persists the complete frontend configuration contract in the Windows desktop app.
- Binds release HTML bytes and release workflow gates to the immutable v0.1.6 archive.
- Limits automatic generation retries to plain, definitive HTTP 429 rejections; cost-risk or accepted/billed evidence takes precedence and requires a user-triggered retry.
- Reports browser history durability explicitly and makes native history commits strict, atomic, and rollback-aware.
- Keeps newer memory-only browser history visible over stale persistent data until a later persistent update succeeds.
- Uses raw Git blob bytes for trusted archive digests and cross-commit historical immutability; earlier checkout-transformed hash claims are superseded.
- Keeps native bridge modules out of the current public static HTML, verifies emitted normal/static artifacts after both builds, and makes output-folder tests collision-safe.
