# GPT-Image-2 Studio v0.1.6

This release closes the P1 findings from the final public-lite branch review.

- Prevents browser-authorized output folders from overwriting existing image files.
- Requests exactly one billed image per Single or Batch task.
- Persists the complete frontend configuration contract in the Windows desktop app.
- Binds release HTML bytes and release workflow gates to the immutable v0.1.6 archive.
- Limits automatic generation retries to bounded HTTP 429 handling so ambiguous provider outcomes are never resubmitted automatically.
- Reports browser history durability explicitly and makes native history commits strict, atomic, and rollback-aware.
- Adds trusted archive digests and cross-commit historical immutability checks for every static version.
- Keeps native bridge modules out of the public static HTML and makes output-folder tests collision-safe.
