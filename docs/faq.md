# 常见问题

## `API key` 保存在哪里？

Web 版本保存在浏览器本地存储中。桌面版本会优先使用系统级安全存储，失败时才回退到当前用户目录下的本地配置文件。配置不会提交到本仓库。

## `Base URL` 是否需要带 `/v1`？

如果你的服务商是 OpenAI compatible 接口，通常建议填写带 `/v1` 的地址，例如 `https://example.com/v1`。如果服务商明确说明不需要 `/v1`，则按服务商文档填写。

## 为什么默认超时时间建议至少 180 秒？

图片生成经常需要 120 到 130 秒。为了避免请求还在生成时被本地提前中断，建议超时至少设置为 180 秒。如果你的服务商更慢，可以在设置页继续调高。

## “响应中没有图片数据”是什么意思？

这表示接口请求返回了成功或近似成功的响应，但响应体里没有可保存的图片内容。常见原因是服务商上游异常、中转站兼容问题、模型临时不可用，或返回格式不符合应用预期。

## 524 错误是什么意思？

524 通常代表服务商或上游服务超时。注意，部分中转站在这种失败下仍然可能计费。本工具不会自动重试图片生成，避免重复消耗费用。

## 图片保存在哪里？

默认保存到 `outputs` 目录。你可以在设置页修改默认输出目录。桌面版本支持打开输出目录；Web 版本受浏览器权限限制，无法直接打开本地文件夹。

## 支持几张参考图？

最多支持 8 张参考图，推荐不超过 4 张。参考图越多，请求越大，也越容易触发服务商限制或超时。

## 为什么测试文字模型通过，但图片模型失败？

文字模型和图片模型可能由不同上游、不同模型名或不同计费链路处理。文字模型通过只代表基础鉴权和文本接口可用，不能保证图片生成一定可用。

## 可以把这个工具部署到服务器给别人用吗？

这个仓库定位为本地工具，不包含用户注册、支付、托管 key、队列、熔断和服务端存储。如果要做面向普通用户的网页平台，建议使用单独的私有平台项目实现。
