# 常见问题

## `API key` 保存在哪里？

在线静态页和单文件 HTML 会保存到当前浏览器的本地存储中。桌面版会使用本地应用配置。配置不会提交到本仓库，也不会上传到作者服务器。

## 别人访问同一个静态页，会不会用到我的 key？

不会。浏览器本地存储按用户、浏览器配置和网站来源隔离。别人访问同一个 GitHub Pages 地址时，只能读取他自己浏览器里的配置。

例外是共享电脑或同一个浏览器用户配置。如果你在公共电脑保存了 key，后续使用同一浏览器的人可能看到。

## `Base URL` 是否需要带 `/v1`？

如果你的服务商是 OpenAI-compatible 接口，通常建议填写带 `/v1` 的地址，例如 `https://example.com/v1`。如果服务商文档明确说明不需要 `/v1`，按服务商文档填写。

## 为什么静态页会遇到 CORS？

静态页从浏览器直接请求模型供应商接口。浏览器会执行跨域安全检查。供应商必须允许你的页面来源、`POST` 方法和 `Authorization` 请求头，否则浏览器会拦截请求。

维护者可以测试：

```powershell
$env:BASE_URL = "https://ruoli.dev/v1"
$env:SITE_ORIGIN = "https://kdb-wind.github.io"
npm run cors:check
```

## 为什么默认超时时间建议至少 180 秒？

图片生成经常需要 120 到 130 秒。为了避免请求还在生成时被本地提前中断，建议超时至少设置为 180 秒。如果服务商更慢，可以在设置页继续调高。

## “响应中没有图片数据”是什么意思？

这表示接口请求返回了成功或近似成功的响应，但响应体里没有可保存的图片内容。常见原因是服务商上游异常、中转站兼容问题、模型临时不可用，或返回格式不符合应用预期。

## 524 错误是什么意思？

524 通常代表服务商或上游服务超时。注意，部分中转站在这类失败下仍然可能计费。本工具不会自动无限重试图片生成，避免重复消耗费用。

## 图片保存在哪里？

HTML 版通常通过浏览器下载机制保存图片。桌面版可以使用本地输出目录。HTML 版受浏览器权限限制，无法像桌面应用一样随意读写本地文件夹。

## 支持几张参考图？

最多支持 8 张参考图，推荐不超过 4 张。参考图越多，请求越大，也越容易触发供应商限制或超时。

## 为什么测试文字模型通过，但图片模型失败？

文字模型和图片模型可能由不同上游、不同模型名或不同计费链路处理。文字模型通过只代表基础鉴权和文本接口可用，不能保证图片生成一定可用。

## 可以把这个工具部署到服务器给别人用吗？

当前公开仓库定位为本地工具和静态 BYOK 工具，不包含用户注册、支付、托管 key、队列、熔断和服务端存储。如果要做面向普通用户的平台，应使用单独的私有平台项目。
