# 本地工具版批量生图验收手册

## 前置条件

- 已填写可用的 `Base URL`、`API key`、文字模型和生图模型。
- 超时时间建议保持 `180` 秒或更高。
- 如需测试图生图批量任务，先在“生成”页添加 1-4 张参考图。

## 验收 1：同一提示词生成多张

1. 启动：`npm run dev`
2. 打开：`http://localhost:5173/`
3. 进入“批量”页。
4. 选择“同一提示词生成多张”。
5. 任务数量输入 `3`。
6. 主任务输入：`一只穿宇航服的橘猫，明亮插画风格`
7. 点击“生成任务列表”。
8. 确认出现 3 个任务，并且每个任务可以编辑标题和提示词。
9. 设置并发 `1`、间隔 `5` 秒、重试 `1` 次。
10. 点击“开始批量生成”。
11. 预期：任务逐个运行，成功后显示缩略图和输出路径，完成后出现汇总提示。

## 验收 2：多行提示词排队

1. 选择“多行提示词排队”。
2. 输入三行：

```text
阿根廷国家队 2026 世界杯宣传海报
葡萄牙国家队 2026 世界杯宣传海报
日本国家队 2026 世界杯宣传海报
```

3. 点击“生成任务列表”。
4. 预期：生成 3 个独立任务，空行会被忽略。

## 验收 3：AI 拆分

1. 选择“AI 拆分”。
2. 拆分模板选择“基础拆分”。
3. 任务数量输入 `5`。
4. 主任务输入：`为 5 个不同国家队生成 2026 年美加墨世界杯宣传海报，整体风格统一。`
5. 点击“调用文字模型拆分”。
6. 预期：文字模型返回 5 条子提示词并回填到任务列表。
7. 手动微调任意一条提示词。
8. 点击“开始批量生成”。

## 验收 4：失败项单独重试

1. 临时把 `Base URL` 改成错误地址并保存。
2. 执行一个 2 条任务的小批次。
3. 预期：任务失败并显示错误信息。
4. 恢复正确 `Base URL` 并保存。
5. 点击失败任务的“重试该任务”。
6. 预期：只重试当前失败任务，不影响已经成功的任务。

## 验收 5：批次文件

1. 批量完成后打开输出目录。
2. 预期：存在类似 `2026-05-17-123012-batch-world-cup-posters` 的目录。
3. 预期：目录中包含图片文件和 `manifest.json`。
4. 打开 `manifest.json`，确认包含批次 ID、标题、执行配置、图片模型配置、任务状态和输出路径。

## 需要特别观察

- 任务运行时页面标题会显示当前完成进度，完成后恢复正常标题。
- `cost_risk` 类异常会暂停整个批次，避免继续消耗费用。
- 修改已生成任务的提示词后，该任务应回到等待状态，重新执行时会重新生成。
- 窄屏下任务卡片、错误信息和输出路径不应横向溢出。
